# Roadmap

## Phase 1 — Foundation (complete)

- Responsive desktop/mobile shell and all nine core modules
- Local shared state, idea capture, approvals, audit, backup
- Calm design system and representative user-specific routines

## Phase 2 — Agent workflows (complete)

- Weekly planner: maximum three outcomes, 30–40% buffer, energy constraints, approval gate
- Project, faith/reflection, health, finance, and relationship workflows
- Clear non-professional boundaries for health and finance

## Phase 3 — Durable brain (operational local adapter)

- Knowledge graph surface, shared audit history, local persistence
- Obsidian-compatible safe import contract: read-only preview before any indexing
- No existing vault is touched

## Phase 4 — Real connectors (requires user-owned credentials)

- Google OAuth client and authorized redirect URL
- Calendar read scope first; write scope only after preview approval
- Tasks, health, and finance adapters remain opt-in and read-only by default

## Phase 5 — Private mobile deployment (requires user approval)

- Select a private hosting/account boundary
- Configure secrets in host, enable authentication, verify backup/restore
- Never publish publicly or create a paid service without approval
